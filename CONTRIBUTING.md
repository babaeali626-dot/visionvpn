# Contributing

- Keep the Hiddify base commit and Core submodule pin documented.
- Preserve every upstream Hiddify capability and its existing UI routes.
- Add Tor transport support only with a real Android executable/library, ABI coverage, license record and integration test.
- Never commit keystores, credentials, bridge lists from private users, or unredacted Tor logs.
- Run format, Flutter tests, Android build and regression checks before release.
- Publish the fork and every release through GitHub Actions in accordance with the upstream license conditions.
